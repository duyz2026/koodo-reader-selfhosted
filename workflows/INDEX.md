### 2. 一键安装脚本 `curl | bash` 🌱
- **一句话**：陌生人一行命令装好整套 koodo-sync-hub（含自动生成强密码、选端口、起服务）。
- **成熟度**：🌱 种子。`install.sh` 已存在，只需加一个 wrapper 下载器。
- **现有素材**：`install.sh`（本地交互安装已验证）、`RELEASE.md` 已列入"待改进项"。
- **相关 Skill**：无专门；可引用 `GitHub` skill（gh CLI）做版本探测。
- **下一步**：写 `curl -sSL https://.../install.sh | bash` 的 bootstrap 脚本 + 校验 digest。

### 3. CI 自动发版 🌱

- **成熟度**：🌱 种子。`RELEASE.md` 流程 A 把"理想态"写成了规范，但没落地流水线。
- **现有素材**：`RELEASE.md`（发布前自检清单、冻结语义）、`VERSION`、`koodo-image.lock`、`CHANGELOG.md`。
- **相关 Skill**：`GitHub` skill（gh issue/pr/release 交互）可作参考。
- **下一步**：写 GitHub Actions 工作流（tag 触发）+ 自检卡点，确保"漏锁 digest 就 fail"。

### 4. 备份恢复演练 🌱
- **一句话**：定期验证备份**能真正恢复**，而非只"生成了备份文件"。
- **成熟度**：🌱 种子。只做过 `koodo-hub backup`（有 `backups/koodo-20260830-072557.tar.gz`），**从没 restore 演练过**。
- **现有素材**：`koodo-hub` 含 backup/restore 子命令；`docs/04-生产环境部署手册.md` 提过备份。
- **相关 Skill**：无。
- **下一步（高优先）**：在临时目录解开备份包，确认书文件/封面/配置齐全；把演练步骤固化成季度例行动作。

### 5. 服务器 SSH 打通 🌱
- **一句话**：从 X1 用 SSH 直连 T460p，省掉"机房本机敲命令"的跑腿。
- **成熟度**：🌱 种子。目前**一直连不上**（密码拒绝 / 直连超时），服务器操作全靠您本机终端。
- **现有素材**：`docs/04` 部署手册、主机指纹记录在 `2026-08-30.md`。
- **相关 Skill**：无。
- **下一步**：排查是密钥未下发还是网络/防火墙拦；建立密钥登录（弃用密码）。

### 6. 光猫 IPv6 防火墙放行 🌱（P0 卡点）
- **一句话**：登录光猫后台，放行 IPv6 入站 8091，让外网设备能访问自建数据源。
- **成熟度**：🌱 种子。iPad 实测两浏览器打不开 8091，根因就是光猫 IPv6 入站拦截。
- **现有素材**：`docs/07-阶段二准备纪要（iPad与Kindle接入）.md` 第十一节实测记录。
- **相关 Skill**：无。
- **下一步（iPad 接入前置）**：进光猫后台放行端口；验证 iPad 浏览器能开 `http://[IPv6]:8091`。

### 7. 公网 HTTPS 接入（域名 + DDNS + Let's Encrypt）🌱
- **一句话**：摆脱动态 IPv6 + HTTP 明文，用固定域名 + 受信证书暴露服务。
- **成熟度**：🌱 种子。服务器 IPv6 带 `dynamic` 标记，会变；无域名拿不到受信证书。
- **现有素材**：Caddy 已就绪（`:80`/`:8091` 反代），`docs/07` 阶段二规划。
- **相关 Skill**：无专门；Caddy 自带 `tls` 自动申请证书能力。
- **下一步**：买域名/免费 DDNS → Caddy 配 `tls` 自动续期 → 改客户端填 https 地址。

### 8. iPad 公网直连接入 🌿
- **一句话**：iPad 通过公网 IPv6（阶段二转域名）连自建数据源，摆脱 Tailscale。
- **成熟度**：🌿 雏形。调研 + 实测完成（`docs/07`），差"光猫放行 + 重配地址"两步未通。
- **现有素材**：`docs/07` 全篇（含实测、CGNAT 判定、备选路径）。
- **相关 Skill**：无。
- **下一步**：完成 #6 后，iPad Koodo 移除旧 Tailscale 域名数据源 → 重添公网/IPv6 地址 → 开自动下载。

### 9. Kindle / KOReader 接入 🌱
- **一句话**：Kindle 装 KOReader，直连 Koodo 同步阅读进度（免自建 kosync）。
- **成熟度**：🌱 种子。发现官方镜像内置 `ENABLE_KOREADER_SERVER=true`（端口 7200，兼容 kosync），但未实操。
- **现有素材**：`2026-08-30.md` 官方文档核实结论。
- **相关 Skill**：无。
- **下一步**：Koodo 容器开 KOReader 服务 → Kindle KOReader 填服务器地址端口 7200 → 验证进度同步。

### 10. OPDS 第三方阅读器接入 🌱
- **一句话**：开 `ENABLE_OPDS=true`，地址「数据源 + /opds」，给第三方阅读器取书。
- **成熟度**：🌱 种子。文档已确认机制，未实操。
- **现有素材**：`2026-08-30.md` OPDS 结论。
- **相关 Skill**：无。
